
# 세계은행 데이터 AI 비교 분석기

이 웹 애플리케이션은 사용자가 세계은행 데이터베이스에서 여러 국가와 경제/사회 지표를 선택하여 시계열 데이터를 시각화하고, Google Gemini API를 활용한 AI 기반 비교 분석 리포트를 받아볼 수 있도록 제작되었습니다.

라이브 데모 : https://sigco3111.github.io/world-bank-board/

[![Live Demo](https://img.shields.io/badge/Live%20Demo-181717?style=for-the-badge&logo=github&logoColor=white)](https://sigco3111.github.io/world-bank-board/)

## ✨ 주요 기능

-   **다국가 비교**: 최대 3개 국가를 선택하여 데이터를 동시에 비교할 수 있습니다.
-   **이중 지표 분석**: 하나 또는 두 개의 다른 지표를 선택하여 이중 Y축 차트에서 동시에 비교 분석할 수 있습니다.
-   **인터랙티브 차트**:
    -   **시계열 추세 (Line Chart)**: 2000년부터 가장 최신 연도까지의 데이터 추세를 시각적으로 확인합니다.
    -   **최신 데이터 비교 (Bar Chart)**: 선택된 국가들의 가장 최신 데이터를 막대그래프로 비교합니다.
    -   **지표 상관 분석 (Scatter Plot)**: 두 개의 지표 간의 상관관계와 분포를 산점도로 분석합니다.
-   **AI 기반 분석 리포트**: Gemini 기능을 활성화하면, 선택된 데이터에 대한 심층적인 비교 분석, 추세, 상관관계, 주요 변곡점 등을 포함한 마크다운 형식의 리포트를 자동으로 생성합니다.
-   **데이터 테이블**: 차트 생성에 사용된 원본 데이터를 테이블 형태로 확인하고 정렬할 수 있습니다.
-   **도움말 기능**: 앱 헤더의 '?' 아이콘을 통해 세계은행 데이터 업데이트 주기에 대한 자세한 안내를 확인할 수 있습니다.
-   **동적 UI**: 사용자 선택에 따라 인터페이스가 즉각적으로 반응하며, 모든 컴포넌트가 유기적으로 연동됩니다.
-   **API 키 관리**: Google Gemini API 키를 브라우저의 Local Storage에 안전하게 저장하고 유효성을 검증합니다.

## 🛠️ 기술 스택

-   **프론트엔드**: React, TypeScript
-   **스타일링**: Tailwind CSS
-   **차트**: Recharts
-   **AI 연동**: Google Gemini API (`@google/genai`)
-   **개발 환경**: 별도의 빌드 과정 없이, `importmap`을 활용한 ES 모듈 방식으로 브라우저에서 직접 실행됩니다.

## 🚀 사용 방법

1.  **API 키 설정 (AI 분석 시 필수)**:
    1.  [Google AI Studio](https://aistudio.google.com/app/apikey)에서 Google Gemini API 키를 발급받습니다.
    2.  애플리케이션 상단의 입력창에 발급받은 키를 붙여넣습니다.
    3.  `저장` 버튼을 클릭하면 키의 유효성을 검사하며, 성공 시 "Active" 상태로 표시됩니다.
    4.  API 키는 브라우저의 Local Storage에 저장되어 다음 방문 시에도 유지됩니다.

2.  **데이터 분석**:
    1.  **국가 선택**: 제어판의 국가 검색창을 통해 비교하고 싶은 국가를 최대 3개까지 추가합니다.
    2.  **지표 선택**:
        -   첫 번째 `지표` 드롭다운에서 분석할 주 지표를 선택합니다.
        -   두 지표를 비교하려면 `+ 비교 지표 추가 (이중 Y축)` 버튼을 눌러 두 번째 지표를 선택합니다.
    3.  **분석 시작**: `비교 분석 시작` 버튼을 클릭하여 데이터 조회 및 차트 생성을 시작합니다.

3.  **결과 확인**:
    -   **차트 유형 변경**: 차트 위의 탭("시계열 추세", "최신 데이터 비교", "지표 상관 분석")을 클릭하여 원하는 차트 유형으로 전환할 수 있습니다.
    -   **AI 리포트 확인**: `Gemini 기능` 토글이 켜져 있으면, 차트 하단에 AI가 생성한 상세 분석 리포트가 표시됩니다.
    -   **데이터 테이블 확인**: 시계열 차트 하단의 `데이터 테이블 표시` 버튼을 클릭하면 차트의 기반이 되는 수치 데이터를 확인할 수 있습니다.

```
.
├── index.html              # 메인 HTML 파일, importmap 및 기본 구조 포함
├── index.tsx               # React 애플리케이션의 진입점
├── App.tsx                 # 메인 애플리케이션 컴포넌트, 전역 상태 관리
```
